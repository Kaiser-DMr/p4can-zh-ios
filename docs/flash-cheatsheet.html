4PIN MX1.25
（转 USB-A）		 P4 原生 USB 2.0 OTG（USB-Serial-JTAG），免驱 可以 可以
固件被编成 USBMode=hwcdc, CDCOnBoot=cdc，所以 Serial 走的是 4PIN 那个口。 只用 Type-C 你会遇到“烧录成功但一行日志都没有”——不是坏了，是日志根本不在那条线上。
最省事：4PIN 一根线全干。手边没有那根线，就用 Type-C 烧 + 4PIN 看。

2烧录：一条命令

工程已经在 ~/WorkBuddy/2026-11-11-17-05-43/ 下备好（目录名已改成与 .ino 一致，tinycrypt 头文件路径已修，已编译通过）。板子插上后：

cd ~/WorkBuddy/2026-11-11-17-05-43
./flash.sh                    # 自动找串口并烧录
./flash.sh /dev/cu.usbmodem1101   # 指定串口
./flash.sh --erase            # 全片擦除后再烧（启动异常时）

脚本内部就是 arduino-cli upload，FQBN 已写死，不用再记参数。

4首次开机是“锁住”的

① 连热点 Wi-Fi 名 P4-CAN-XXXX（MAC 后两字节），密码 12345678
② 打开网页 浏览器访问 http://192.168.4.1
③ 选车型 你的车：Model Y Legacy → 拓扑选 BODY + CHASSIS + PARTY
④ 保存重启 点 Save Profile & Reboot，板子自己重启后才开始发帧
没保存 profile 之前，CAN 发送、注入、蓝牙全部关闭（fail-closed 设计）。这是正常的，不是刷坏了。

现象原因 / 处理

Failed to connect / 连不上芯片 手动进下载模式：按住 BOOT → 点 RST → 松开 BOOT，然后立刻跑脚本
烧录成功但没有日志 日志口是 4PIN OTG，不是 Type-C；波特率 115200
反复重启 / 启动即挂 ./flash.sh --erase 全片擦除后重烧（换了 core 版本或分区表会这样）
编译报 tinycrypt 找不到 已修：头文件复制到 sketch 根目录的 tinycrypt/。若重新解压仓库需重做一次

6烧完先别装车

台架三步，逐条确认再接线：

  1. 串口日志里 三路 CAN 都初始化成功，没有 TWAI install failed。
  2. 进网页看 Home 页三张 CAN 卡：没接总线时应显示 WAITING / No frames yet；接上模拟器后变 LIVE 并跳帧数。哪一路不跳，就是那一路 A/H 接反或收发器没供电。
  3. 拿第二块板（或 USB-CAN）发 0x3FD / 0x399，确认 NAG 和 R79 的 TX 计数会涨、Dashboard 有反应。
装车前必做：3 个 SN65HVD230 上的 120Ω 要拆掉（车上两端已有终端）。拆下来的 3 颗别扔——台架单节点时需要它们当终端，正好插在模块的 CANH/CANL 排针上。
这是 BETA 固件。 仓库 VALIDATION.md 明确写着“未烧录、未接 CAN、未路测”。NAG-killer 本质是抑制驾驶员监控，公开道路使用既不安全也可能违反当地法规，并影响质保与保险。
