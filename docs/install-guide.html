P4CAN iOS App 已编译 · 待签名

把车上的 P4-CAN 控制器网页包装成原生 App：全屏无地址栏、自带连不上时的引导页、支持横屏与下拉刷新。界面已按 iOS 26 的液态玻璃（Liquid Glass）体系重做。

安装包

Bundle ID
com.p4can.universal
版本
1.3.0 (Build 4)
最低系统
iOS 16.0（iOS 26 及以上启用液态玻璃，旧系统自动回退材质，版式不变）
架构
arm64（真机，不含模拟器切片）
签名状态
未签名 —— 本机没有 Apple 开发者证书，需你用自己 Apple ID 签一次
为什么要自己签名：iOS 不允许安装任何未签名 App。本机执行 security find-identity 返回 0 个证书，所以只能交付「未签名 IPA」，由下面的工具用你的 Apple ID 现场签名再装。

2三种装法怎么选

方式需要有效期适合
Sideloadly Mac/Windows + 数据线 + 免费 Apple ID 7 天 最快，十分钟装完
Xcode 直接 Run 这台 Mac + Xcode（已装 27.0） 7 天 要改代码、调试日志
AltStore / SideStore 先装 AltServer，同一 Wi-Fi 自动续签 长期日常用
付费开发者账号 $99/年 1 年 不想每 7 天折腾

免费 Apple ID 的 7 天限制是苹果规则，与 App 无关；到期后重装即可，车辆数据和网页偏好不会丢在设备端。

3方式 A：Sideloadly（推荐先试）

  1. 从 sideloadly.io 下载 Mac 版并打开。
  2. iPhone 用数据线连 Mac，手机上点「信任此电脑」。
  3. 把 dist/P4CAN-1.3.0-unsigned.ipa 拖进 Sideloadly 窗口。
  4. 在 Apple ID 一栏填你的 Apple ID，点 Start，输入密码（部分账号需要 App 专用密码）。
  5. 装完在手机上：设置 → 通用 → VPN 与设备管理 → 开发者 App → 选你的 Apple ID → 信任。
装好后桌面出现「P4-CAN」图标：蓝紫玻璃质感的字母 T 方块，深色桌面下边框会有一圈高光。

4方式 B：Xcode 直接跑（本机现成）

工程已经在 P4CAN-iOS/P4CAN.xcodeproj，双击打开即可：

  1. Xcode 顶部选中 P4CAN target → Signing & Capabilities。
  2. 勾上 Automatically manage signing，Team 选你的个人 Apple ID（没有就 Add an Account 登录一下）。
  3. 如果提示 Bundle ID 被占用，把 com.p4can.universal 改成 com.你的名字.p4can。
  4. iPhone 插上，顶部设备选你的手机，按 ⌘R。

命令行重新出包：

cd P4CAN-iOS
./build-ipa.sh          # 产出 dist/P4CAN-1.3.0-unsigned.ipa

5第一次打开要注意

现象说明
弹「查找本地网络设备」 点 允许。不允许就连不上 192.168.4.1，这是 iOS 14+ 的强制权限。
提示「无线局域网无互联网连接」 点 保持连接，不要点断开。设备热点本来就不通外网。
首页停在「连接步骤」页 说明还没连上热点。App 每 3 秒自动探测，连上会自动跳进仪表盘。
热点名不是 P4-CAN-XXXX 网页里改过 Wi-Fi 配置的话，AP 名会变；或长按复位键回 AP 模式。
装车前提醒：仪表盘上的功能开关直连车辆总线，务必在停车、P 挡状态下配置；行驶中不要在手机上操作。App 本身不含任何控制逻辑，所有功能与安全策略都在固件里。

6常见报错

报错处理
Unable to install "P4CAN"换根数据线 / 换 USB 口；确认手机已解锁并信任电脑。
The app ID cannot be registeredBundle ID 撞车，改成 com.你的名字.p4can 重签。
无法验证 App没信任描述文件，去「设置 → 通用 → VPN 与设备管理」点信任。
闪退 / 图标灰掉免费证书已过期（7 天），重新签一次。
iOS 15 及以下装不上最低 iOS 16.0，需在工程里把 Deployment Target 调低后重编。

7App 里有什么

页面作用
连接引导页三步图文说明热点连接、一键跳「无线局域网」设置、手动改设备 IP、连不上的排查清单。
仪表盘（网页）设备自带页面，已汉化成中文，功能完全一致。
设置面板设备地址、保持屏幕常亮、清除网页缓存、重新加载、版本信息。以半透明材质 sheet 呈现，底下内容仍在。

仪表盘页面上没有叠加任何原生浮动按钮——设备网页自带的悬浮底部导航和右侧开关会被压住。 进 App 设置的办法：网页「设置 → 系统 → P4-CAN App」那一行（装的是汉化固件时）； 原厂固件没有这一行，长按页面 0.7 秒即可，首次进页面会飘一次提示。下拉页面可刷新。

8界面用的是液态玻璃

层面做法
控制层浮动按钮、底部操作条、失败横幅用 glassEffect（iOS 26+），带淡色 tint 与按下缩放反馈。
内容层卡片与列表用标准材质 .regularMaterial + 半透明描边。官方 HIG 明确玻璃属于控制层，铺满内容区会打散层级。
合并渲染底部按钮同处一个 GlassEffectContainer，靠近时玻璃会自然融合。
底部两个按钮「打开无线局域网设置」与右侧刷新键同为 46pt 高，中心线对齐。主按钮是无色磨砂玻璃 + 淡青 tint，不是实心色块；主次由品牌色图标与字重表达。
窄屏与大字号宽度不足时主按钮自动收成图标；辅助功能字号（≥ 辅助功能 3）直接转图标，保证不截字、高度不膨胀。
背景纯色磨砂：单一纯色 + 一层极细噪点，没有彩色光晕与渐变亮带。玻璃靠自身顶亮下暗的边缘高光被辨识。
明暗切换设置 →「外观」可选 跟随系统 / 浅色 / 深色，深浅各一套完整配色，切换即时生效。
无障碍全量语义字号（Dynamic Type）、触控区 ≥44pt、玻璃不受「减弱透明度」影响（系统自动处理）。

设计稿见 P4CAN-iOS-液态玻璃设计稿.html，可对照看版式与玻璃层次的预期效果； 深浅两套的实际运行截图见 P4CAN-iOS-运行截图-深色.png / -浅色.png。

9浅色与深色

项说明
怎么切设置面板 →「外观」→ 跟随系统 / 浅色 / 深色。选择会保存，下次启动沿用。
为什么进仪表盘变深设备自带网页是深色的，浅色状态栏压上去读不清，因此在线状态固定深色。
浅色下改了什么品牌青绿由 #4AD9C2 压深到 #0B8778，白底上的正文对比度约 4.5:1；卡片描边改用黑 8%，阴影减到 10%。

10配原厂固件还是汉化固件

页面仍然全部来自设备 http://192.168.4.1/，但 App 自己带了一份汉化脚本， 加载后注入网页 —— 所以刷原厂英文固件，看到的也是中文：

刷的固件界面语言功能怎么进 App 设置
原厂 v3.29.3中文（App 注入）全部正常长按页面 0.7 秒
打了汉化补丁中文（固件自带）全部正常网页「设置 → 系统 → P4-CAN App」

两条路径不会打架：补丁里有单例守卫，固件已经内置汉化时，App 注入的那份直接退出。 想把界面换回英文，App 设置 → 语言 → 关掉「中文界面」即可，立刻重新加载生效。

汉化只改前端页面：把英文文本节点换成中文（placeholder / title / aria-label 一起换）， 不拦截任何请求、不改事件处理、不碰固件逻辑（CAN / AP / Profile 都在 .ino 里，未改动）。 中文因此能选中、能复制、Ctrl+F 也搜得到。 代价是页面 gzip 体积 82 KB → 109 KB，首屏多传 27 KB，软 AP 上约多 0.1–0.2 秒。
